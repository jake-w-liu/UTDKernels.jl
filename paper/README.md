SoftwareX article describing `UTDKernels.jl`.

## Contents

| File | Role |
|------|------|
| `generate_paper_data.jl` | Regenerates every CSV in `data/` |
| `plot_paper.jl` | Regenerates every figure in `figs/` from `data/` |
| `data/` | CSV source for all figures and tables (regenerated; not tracked) |
| `figs/` | Publication figures (PDF) |

## Reproducing

Run from this directory. The scripts activate the package environment
automatically; `CSV`, `DataFrames`, `ForwardDiff`, and `PlotlySupply` must be
available (for example in the default Julia environment).

```bash
# 1. Regenerate the data (writes data/*.csv)
julia --project=.. generate_paper_data.jl

# 2. Regenerate the figures (writes figs/*.pdf)
julia --project=.. plot_paper.jl
```

A single figure can be rebuilt by name, e.g. `julia --project=.. plot_paper.jl gtd`.

## Data files

All `data/*.csv` are generated by `generate_paper_data.jl` and are intentionally
**not** tracked in git; run the script to recreate them. The figure that
cross-validates against the Balanis `WDC.m` reference (`figs/balanis_validation.pdf`)
additionally reads `../validation/data/wdc_reference.csv`, which is produced by
`../validation/generate_wdc_reference.m` (no MATLAB toolboxes required) and is
likewise untracked.
